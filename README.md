# Odin Library

A small library app that keeps track of books, written in plain HTML, CSS and JavaScript.

## Features

- Add books through a form: title, author, notes, page count and read status
- Each book is rendered as a card you can toggle between read and not read
- Delete books you no longer want in the list
- Books are held in memory, so the list resets on reload

## Running it

Open `index.html` in a browser.
